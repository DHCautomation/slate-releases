SlateTap releases

Firmware for the SlateTap ST-1 · DHC Automation and Controls

Update a SlateTap that runs

  • 0.3.0 and later: System > Updates: pick the channel (Stable for sites, Beta for test units), Check now, then Update to <version>. The unit downloads both images and checks them itself.
  • 0.2.0: Settings > Fleet, update manifest URL https://dhcautomation.github.io/slate-releases/slatetap-st1/stable/versions.json (or .../beta/versions.json), then Check and Update. Once on 0.3.x, the unit keeps that channel by itself.
  • Without internet on the unit: download the firmware and the web app images of a version below on a phone or laptop, then install them by file: the firmware first, then the web app (a unit back on 0.2.0 after it had users on 0.3.x: the web app first, then the firmware).
  • From 0.3.0-rc.1 a unit installs DHC's signed files only. To go back to 0.2.0 by file, use the signed copies of its two files listed with each release from 0.3.0-rc.1 ("0.2.0 firmware (signed)", "0.2.0 web app (signed)").

Flash a new or wiped unit

  • Open the version's Flash (USB) page in Chrome or Edge on a computer. Phones and Firefox cannot flash.
  • USB only: disconnect the 24 VAC wires first. USB and 24 VAC are never connected at the same time.
  • A fresh install erases the unit: settings, programs and points are lost. Take a backup of a running unit first.
