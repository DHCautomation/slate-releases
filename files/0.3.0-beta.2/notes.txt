Phase SC of 0.3.0: the BACnet/SC node, SC routing, Network Port and File objects, and standard commissioning.

- BACnet/SC node: TLS 1.3 with mutual authentication to the site's hub, primary and failover hubs, reconnect with a growing backoff, and errors in words (another CA, another name, an expired certificate, a hub that does not trust ours). Connections > BACnet > SC shows the state, the hubs, the certificates and the commissioning steps.
- Routing: SC is a network of the built-in router beside MS/TP and BACnet/IP, so the devices behind a SlateTap are reachable from the SC side.
- Standard commissioning: Network Port objects for every data link, File objects for the certificates (AtomicReadFile, AtomicWriteFile), a key pair and request made on the device, ReinitializeDevice ACTIVATE_CHANGES. Configuration over BACnet is off by default; ReinitializeDevice needs it on and a password (8 to 20 characters, with a lockout).
- More internal memory headroom: with everything on, BACnet/SC connected and an update running, the lowest free internal heap was 102 KB (beta.1: 76 KB).
- BVLC-SC 2-octet fields go out most significant octet first (a patch to bacnet-stack 1.6.1, published in LICENSES/ on the release site).
- Tested against our own hub; not yet against another vendor's.
- Install on 0.2.0 or 0.3.0-beta.1: the firmware image, then the web image. A new or wiped board: the flasher page (merged image).
