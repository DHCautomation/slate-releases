SlateTap ST-1 firmware 0.3.1-beta.12 · DHC Automation and Controls

Beta 12 of 0.3.1: DHC staff sign in once, new units enrol with DHC by themselves, and DHC can name a new unit. Release notes

Before you plug in

  1. USB only. Disconnect the 24 VAC wires (J2 24V/COM) first. USB and 24 VAC are never connected at the same time.
  2. A fresh install erases the device: settings, Logic programs and points are lost. On a running SlateTap, download a backup first (0.3.x: System > Backup; 0.2.x: Settings > Backup and restore).
  3. To update a SlateTap that already runs, you do not need this page: use System > Updates (0.3.x), or install slatetap-0.3.1-beta.12.bin, then www-0.3.1-beta.12.bin by file (0.3.x: System > Updates > Install from file; 0.2.x: Settings > Firmware update).

Install

  1. Use Chrome or Edge on a computer (Web Serial). Phones and Firefox cannot flash.
  2. Connect the SlateTap's USB-C port to the computer. The green PWR LED lights.
  3. Press the button and pick the port called USB JTAG/serial debug unit (Windows: "USB Serial Device").
This browser cannot flash devices. Use Chrome or Edge on a computer. Flashing needs a secure page (https or localhost).

If no port appears or the install fails to connect: hold BOOT, tap RESET, release BOOT, and try again. When the install finishes, unplug and replug USB (or tap RESET) to start the new firmware.

After the install

  1. The OLED shows the SlateTap splash, then the Wi-Fi card with a QR code.
  2. Join Wi-Fi SlateTap-XXXX (password slatetap1) and open http://10.10.10.1.
  3. A new unit (0.3.x) starts a short wizard: site name, admin password, time zone, Wi-Fi, BACnet mode.
  4. Restore your backup if you took one (0.3.x: System > Backup; 0.2.x: Settings > Backup and restore).
